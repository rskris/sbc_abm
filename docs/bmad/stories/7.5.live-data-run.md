# Story 7.5 — Live-data validation run (runbook)

**Epic:** 7 — Calibration, validation & reporting · **Status: Ready — awaiting environment (OD2)**

All *code* for this story is delivered; what remains is executing it in an
environment whose network policy allows the public-data hosts. This runbook is
the reproducible procedure.

## 1. Environment setup (the OD2 decision)

The run needs outbound HTTPS to exactly these hosts (also enumerated by
`sbcabm preflight`, sourced from `data/sources.py`):

| Host | Data |
|---|---|
| `api.census.gov` | ACS marginals, PUMS seed records |
| `www2.census.gov` | TIGER/Line polygons, Gazetteer centroids |
| `lehd.ces.census.gov` | LODES employment |
| `download.geofabrik.de` | OpenStreetMap network extract |
| `www.sbmtd.gov` | SBMTD GTFS transit feed |

For **Claude Code on the web**: edit the environment's **network policy**
(claude.ai/code → your environment → settings) to allow these domains — or use
an unrestricted policy — then start a **new session** in that environment.
Details: <https://code.claude.com/docs/en/claude-code-on-the-web>.
For any other machine: ensure the proxy/firewall allows the hosts.

Optional: set `CENSUS_API_KEY` (free from census.gov) for higher rate limits.
Install extras for full capability: `pip install -e ".[dev,geo,osm]"`.

## 2. Preflight (must PASS)

```bash
sbcabm -c configs/live.yaml preflight
```

This verifies every host is reachable **and** that the ACS/PUMS variable
scheme in `popsyn/specs.py` exists in the live API for the configured vintage
(the scheme was authored from documented table structures; this check closes
Epic 1's carry-forward). Exit code 0 = ready.

If any variable is reported missing, adjust the affected `ControlSpec` in
`src/sbcabm/popsyn/specs.py` for the vintage before proceeding.

## 3. Run

```bash
sbcabm -c configs/live.yaml run --write
```

`configs/live.yaml` sets `data.strict: true` — a failed required ingest aborts
rather than silently degrading to fixtures, so a completed run is guaranteed
live. Downloads cache under `data/cache/`; re-runs are download-free. Outputs
land in `outputs/live/`.

Expected scale: ~270 block groups for SB County (FIPS 06083), ~150k households
/ ~450k persons synthesized; OSM drive network for the county; the full stage
list through `measures`.

## 4. Publish the evidence (acceptance)

1. `popsyn_diagnostics.csv` — per-zone IPU convergence (gaps, relaxed controls).
2. `equilibrium_history.csv` — skim RMSE by iteration.
3. `measures.csv` — the standard measure set.
4. Preflight output showing the variable scheme verified.

Attach these to the PR (or commit under `docs/validation/`) and flip this
story to Done. Calibration against observed targets is then unblocked
pending OD1 (target data choice).
