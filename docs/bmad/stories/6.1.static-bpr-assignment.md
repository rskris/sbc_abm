# Story 6.1 — Static BPR assignment

**Epic:** 6 — Assignment & equilibrium · **Status: Approved** · **Priority: next**

## Story

As a modeler, I want auto trips assigned to network links with volume-delay
(BPR) feedback, so that congested link travel times and link volumes exist for
skim feedback and reporting.

## Context for the dev agent

- Inputs already in the data store after `modechoice`: `trips` (with
  `origin_zone`, `dest_zone`, `mode`, `depart_hour`), `network_nodes`,
  `network_links`, `zone_connectors`.
- Reuse `network.graph.Network.mode_graph("drive")` for routing;
  `zone_connectors` maps zones to entry nodes.
- Only auto modes (`drive_alone`, `shared_ride`) are assigned; active/transit
  volumes are out of scope here.
- Time periods follow `activitygen.scheduling.period_of` over `depart_hour`.

## Tasks

1. `src/sbcabm/assignment/__init__.py` + `static.py`:
   - `LinkState` (capacity, free-flow time) derived from `network_links`
     (`capacity_per_lane` default 1800 veh/hr, `lanes` default by speed class —
     document defaults in the module docstring).
   - `assign_static(trips, network, connectors, *, periods, alpha=0.15,
     beta=4.0, max_iterations=20, tolerance=1e-3)` implementing MSA:
     all-or-nothing shortest paths on current times → averaged volumes →
     BPR time update → repeat.
   - Returns `AssignmentResult(link_volumes, congested_times, diagnostics)`.
2. `src/sbcabm/assignment/stage.py`: `run_assignment` reading the store,
   writing `link_volumes`, `congested_times`, `assignment_diagnostics`;
   register in `pipeline.build_default_registry()`; config stage list already
   names `assignment`.
3. Tests in `tests/test_assignment.py`.

## Acceptance criteria

1. Trip conservation: total assigned volume per period equals the number of
   auto trips in that period (shared_ride may carry an occupancy divisor,
   default 1.0 — if so, document and test it).
2. Congested link time ≥ free-flow time on every link; strictly greater on
   links with positive volume when v/c > 0.
3. MSA converges on the fixture network (diagnostics show decreasing relative
   gap; converged flag set within max_iterations).
4. Determinism: identical inputs + seed ⇒ identical volumes.
5. Stage integration: offline `pipeline.run([... , "assignment"])` produces the
   three tables; `assignment` raises a clear KeyError without `trips`.
6. `ruff check src tests` exits 0; full pytest suite passes.

## Out of scope

Transit/active assignment, dynamic mobsim (story 6.3), skim feedback (6.2).
